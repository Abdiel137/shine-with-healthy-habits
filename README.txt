SHINE WITH HEALTHY HABITS PROJECT — WEBSITE STARTER

Files:
- index.html: website content
- styles.css: modern, responsive design
- script.js: mobile navigation and contact form draft
- assets/shine-logo.jpg: logo supplied by the project owner

PREVIEW:
Open index.html in a web browser.

BEFORE PUBLISHING:
1. Add the official SHINE contact email in script.js (projectEmail variable).
2. Replace the placeholder contact details with the project's approved phone/email.
3. Add approved photos to a Gallery section only after receiving appropriate consent.
4. Decide whether to add a real registration form. Because the project serves children, get guardian consent and use a secure form/service; do not collect children's sensitive information in an unprotected static website.
5. Check all content and contact details with the project team.
6. Upload the files to a hosting service such as GitHub Pages or Netlify. The site is not online until you complete this step.

The contact form is deliberately not a database form and does not store submissions. With an official email configured, it prepares a message in the visitor's email application.
